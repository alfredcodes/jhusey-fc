## Review limitations
Search-indexed GitHub pages can show mirrors, forks or stale README snapshots. Before installing or copying anything, inspect the exact requested repository's current default branch, `LICENSE`, latest commits, skill source files and install scripts. Do not run repository-provided shell installers without reading them first. The research report deliberately does not claim every repository's license or current maintenance status has been conclusively verified.
